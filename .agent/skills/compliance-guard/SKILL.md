# Compliance Guard — 合规审查

## 能力范围
- **投资建议词扫描**：检查用户可见文案是否包含以下禁用词：
  `买入、卖出、持有、加仓、减仓、目标价、必涨、稳赚、抄底、逃顶、强烈推荐`
- **T3 传闻标注检查**：所有 T3 来源内容必须标注 `"未证实"` 或 `"市场传闻"`，不得与权威信息混排
- **概率表述合规**：V1 仅允许使用 `高/中/低`，禁止精确百分比（如 `"80%概率"`）
- **建议关注节点澄清**：`建议关注` 仅指"信息关注节点"，非"建议操作"
- **免责声明检查**：确保发现 Tab、参谋 Tab、事件详情页均有常驻免责声明入口或文案
- **个人指控拦截**：不做针对具体个人的指控性推断

## 输入
- `EventCard` 对象（headline、directions、rumors、timeline 节点摘要）
- 页面文案字符串
- 对话回复文本

## 输出
- 审查报告：
  ```
  [PASS] / [BLOCK]
  问题列表：
  1. [级别: 阻塞] directions[0].scenario 含"建议买入" → 违反红线
  2. [级别: 警告] rumors[0] 未标注来源可信度
  修复建议：...
  ```

## 阻塞性红线（PRD §5.1）
| 红线 | 处理方式 |
|------|----------|
| 出现买卖建议词 | 阻塞，必须删除或改写 |
| T3 内容未标注 "未证实" | 阻塞，必须添加标注 |
| 精确百分比概率 | 警告，V1 改为高/中/低 |
| 缺少免责声明 | 警告，必须补充 |
