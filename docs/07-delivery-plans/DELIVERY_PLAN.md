## 二、依赖关系

```
P0 数据层（iFinD + Serper）
      │
      ▼
P1 规则层（状态机 + 合规）  ◀── 独立于数据源，可先行
      │
      ▼
P2 Agent 层（采集 → 分析 → 参谋）
      │
      ├──▶ P3 前端（发现 / 参谋 / 我的）
      │
      └──▶ P4 自动化（调度器 + 反思）
                  │
                  ▼
            P5 提交（仓库 + 公网 URL + 文档）
                  │
                  ▼
            P6 演示视频
```

**可并行**：P1 规则层与 P0 数据层无依赖，可同时进行。
