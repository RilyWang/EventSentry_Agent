# EventSentry 事件参谋 — 迭代开发 Prompt（v2.0）

## 一、任务背景

你是一名全栈工程师，正在迭代一个已具备基础架构的移动端投资事件追踪应用 **EventSentry 事件参谋**。上一版本已完成：React + TypeScript + Tailwind 三 Tab 骨架、静态事件卡片、localStorage 用户存储雏形。本版本需根据以下新要求完成改造，最终交付一个**任何人点击即可访问的公开网址**。

## 二、需要修改的部分（4 项）

### 1. 发现 Tab 信息流改造（核心）
- **现状**：静态事件列表，卡片结构单一
- **目标**：改为"信息流"形态
  - 用 **iFinD MCP** 自行挖掘 **3-5 个围绕单只股票主体的大事件**（如宁德时代、比亚迪等热门标的）
  - 每个大事件生成一个 **主流卡片**（Face 态），按时间倒序排列
  - 卡片必须包含：利好/利空/风险标签 + 事件主名称 + 横向时间线节点 + 当前节点状态 + 可信度
  - 数据来源必须真实调用 iFinD API（公告、业绩预告、研报等），不允许凭空编造
  - 数据获取在构建期完成，序列化为静态 JSON 随前端打包

### 2. 参谋 Tab 对话 Agent 增强
- **现状**：前端硬编码关键词匹配
- **目标**：
  - 支持自然语言查询（如"宁德时代最近有什么大事"）
  - 返回结果必须是"事件判断卡片"（Face 态缩略卡片）
  - 点击卡片进入详情页（双 Tab：事件脉络 + 其他说法）
  - 保留推荐提问引导语

### 3. 用户注册系统（必须实现）
- **现状**：仅昵称登录
- **目标**：
  - 支持完整注册流程：输入昵称 → 生成用户 ID → 写入 localStorage
  - 注册后进入"我的"Tab，可管理：持仓列表、关注股票、风险偏好
  - 已注册用户二次打开免登录；提供退出登录入口
  - 未登录用户访问"我的"Tab 时强制弹出注册框

### 4. 部署交付（硬性要求）
- **目标**：应用以**公开可访问的网址**交付，**优先 GitHub Pages**
- **实现方式**：
  - 纯前端构建：所有数据预加载、用户系统用 localStorage，确保 `dist/` 可独立静态托管
  - 同时提供 GitHub Pages 部署方案（gh-pages 分支 / GitHub Actions）
  - 交付物必须包含：线上可访问 URL + 完整可运行的项目源码

## 三、输入

| 输入项 | 说明 |
|---|---|
| 现有项目代码 | React + TS + Vite + Tailwind + shadcn/ui 项目，路径 `/mnt/agents/output/app` |
| iFinD MCP 工具 | 数据源插件，支持股票公告（`ifind_get_stock_announcement`）、业绩预告、行情等 |
| 产品设计文档 | BRD/PRD 已定义三 Tab 结构、卡片 Face/Back 双态、T0-T3 证据分层、时间线折叠规则 |
| 合规红线 | 不预测股价、不推荐买卖、免责声明常驻 |

## 四、输出要求

1. **可运行应用**：`npm run dev` 本地可运行，`npm run build` 无报错
2. **线上 URL**：提供至少一个公开可访问的部署地址
3. **GitHub Pages 就绪**：`dist/` 目录 + `vite.config.ts` 的 `base` 配置正确 + 部署说明文档
4. **真实数据**：发现 Tab 的事件数据必须来自 iFinD API 真实返回，标注数据获取时间与来源
5. **代码质量**：TypeScript 类型完整、`npm run check` 零错误、组件拆分合理

## 五、约束

- **移动端优先**：底部三 Tab 导航（发现-参谋-我的），页面宽度 max-w-md 居中
- **纯静态**：GitHub Pages 无后端，禁止依赖任何服务端 API、数据库、SSR
- **真实合规**：所有事件数据可溯源；不提供买卖建议；免责声明常驻底部
- **折叠规则**：时间线超过 1 年的节点默认折叠，可点击展开
- **传闻隔离**：T3 传闻必须出现在时间线但默认弱化展示（灰色、标注"未证实"），不出现在 Face 态主线结论中
- **性能**：构建产物 gzip 后 JS ≤ 200KB，首屏加载 ≤ 2s

- [ ] 新用户打开应用 → 进入"我的"Tab → 弹出注册框 → 注册成功 → 可添加持仓
- [ ] 刷新页面后用户状态保持
- [ ] 提供公开访问 URL
