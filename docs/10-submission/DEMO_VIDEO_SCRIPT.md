# 演示视频分镜脚本（60–180 秒）

> EventSentry（事件参谋）｜ 建议时长 **150 秒** ｜ 竖屏录制（手机比例 9:16）优先
>
> 录制前准备：
> 1. 启动服务 `cd server && python main.py`
> 2. 浏览器打开 `http://localhost:3000/`，按 F12 → 设备模拟 → iPhone / 430px 宽
> 3. 清空浏览器缓存（Ctrl+Shift+R）以确保加载最新样式

## 建议强化的 3 个"可追溯"画面（评委关注点）

1. **规则编号**（35–55s）：停在版本链上，让 `Rule 1` / `Rule 4` / `Rule 7` 清晰可见
2. **来源与日期**（70–85s）：放大证据条目，展示"公司公告 / 2026-10-08 / iFinD"字样
3. **引用卡**（115–140s）：放大参谋回答下方的"📎 数据来源（iFinD/同花顺 · 可追溯）"区块

## 录制提示

- **时长控制**：按上表节奏约 150 秒，符合 60–180 秒要求
- **重点**：不要全片匀速；在"规则编号""来源日期""引用卡"三处**停顿 2–3 秒**让评委看清
- **避免**：不要展示终端滚动日志（噪音大），聚焦产品界面
- **字幕**：建议加中文字幕，便于评审

## 一句话开场（可直接用作视频简介）

> **EventSentry 事件参谋**：让同一投资事件的公告、新闻、研报、传闻变成一条可追溯的证据时间线——每次状态变化都记录触发规则，每个结论都标注来源与层级。
