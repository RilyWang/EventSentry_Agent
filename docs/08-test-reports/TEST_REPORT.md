## 三、数据 / 接口异常测试

| 用例 | 现象 | 处理 | 结果 |
|------|------|------|------|
| **iFinD 新闻接口返回空** | `search_news` 恒返回 0 条 | 改用 Serper 采集 T1/T2/T3 | ✅ 已绕过 |
| **iFinD 股票接口格式不同** | `data` 为 `{"answer": markdown}` 而非 JSON 数组，原解析丢弃数据 | 修复 `parse_ifind_records` 兼容两种格式 | ✅ 已修复 |
| **iFinD 热点接口参数非法** | `time_scope="一周"` 报 `must be set in enums value` | 探测出合法值 `24小时` | ✅ 已定位 |
| **glm-4-flash 不可用** | HTTP 500 `Internal Network Failure` | 自动降级 glm-4.6 | ✅ 已兜底 |
| **LLM 返回非 JSON** | 带 markdown 围栏 / 返回字符串数组 | `_extract_json` 容错 + `isinstance(dict)` 过滤 | ✅ 已修复 |
| **SQLite 并发写锁** | `database is locked` | 全程复用同一 cursor，每标的处理完即提交 | ✅ 已修复 |
| **标的处理失败丢数据** | 失败标的消息被误标已处理 | 仅标记成功标的的消息 | ✅ 已修复 |
| **网络代理拦截** | 环境 SOCKS 代理导致请求失败 | 客户端统一 `proxies={http:None,https:None}` + `no_proxy` | ✅ 已绕过 |
| **端口占用** | 3000 被占 | 返回明确错误，需先释放端口 | ✅ 提示清晰 |

## 四、合规边界测试

**方法**：`python rules/compliance.py` 自测

| 用例文本 | 期望 | 实际 | 结果 |
|---------|------|------|------|
| "建议买入该股票，目标价100元" | 阻塞 | BLOCK（红线词：买入、目标价） | ✅ |
| "该事件可能带来一定影响" | 警告 | WARN（绝对化表述"一定"） | ✅ |
| "上涨概率80%" | 警告 | WARN（精确百分比） | ✅ |
| "公司公告确认合作，实际落地情况待观察" | 通过 | PASS | ✅ |
| T3 传闻未标注"未证实" | 阻塞 | BLOCK | ✅ |

**红线词表**：买入 / 卖出 / 持有建议 / 加仓 / 减仓 / 目标价 / 必涨 / 稳赚 / 抄底 / 逃顶 / 强烈推荐 / 保证收益 / 无风险 / 保本

**产品内约束**：
- 参谋 System Prompt 明确禁止预测股价、给买卖建议、使用绝对化表述
- 卡片生成后**强制过合规扫描**，违规即标记
- 概率只允许"高/中高/中/中低/低"，禁用精确百分比
